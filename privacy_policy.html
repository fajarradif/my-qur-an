Kebijakan Privasi - MyQuran

Terakhir diperbarui: 10 Juli 2026

Aplikasi MyQuran ("Aplikasi") dibuat oleh Fajar Radif sebagai aplikasi gratis. Layanan ini disediakan tanpa biaya dan dimaksudkan untuk digunakan apa adanya.

Halaman ini digunakan untuk memberi tahu pengguna mengenai kebijakan kami tentang pengumpulan, penggunaan, dan pengungkapan Informasi Pribadi jika ada orang yang memutuskan untuk menggunakan Aplikasi kami.

1. Pengumpulan dan Penggunaan Informasi

Aplikasi ini sangat menghargai privasi Anda. Kami tidak mengumpulkan, menyimpan, atau mengirimkan informasi pribadi apa pun dari pengguna ke server eksternal kami.

Aplikasi memerlukan izin tertentu untuk dapat berfungsi secara optimal:

  • Akses Lokasi (Approximate Location): Lokasi perangkat Anda diproses secara lokal di perangkat Anda hanya untuk menghitung dan menentukan jadwal sholat yang akurat sesuai dengan wilayah Anda. Informasi lokasi ini tidak pernah disimpan, diunggah, atau dibagikan ke pihak mana pun.

2. Layanan Pihak Ketiga

Aplikasi menggunakan API publik gratis (seperti MyQuran API dan Republika News API) untuk memuat data jadwal sholat, ayat Al-Qur'an, dan warta berita. Layanan pihak ketiga ini tidak menerima informasi identitas pribadi apa pun dari Aplikasi kami.

3. Keamanan

Karena Aplikasi kami tidak mengumpulkan informasi pribadi apa pun dari perangkat Anda, tidak ada risiko kebocoran data pribadi Anda dari sistem kami.

4. Perubahan pada Kebijakan Privasi ini

Kami dapat memperbarui Kebijakan Privasi kami dari waktu ke waktu. Oleh karena itu, Anda disarankan untuk meninjau halaman ini secara berkala untuk mengetahui perubahan apa pun. Kami akan memberi tahu Anda tentang perubahan apa pun dengan memposting Kebijakan Privasi baru di halaman ini.

5. Hubungi Kami

Jika Anda memiliki pertanyaan atau saran tentang Kebijakan Privasi kami, jangan ragu untuk menghubungi kami.
